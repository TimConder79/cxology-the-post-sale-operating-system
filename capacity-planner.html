07 · Methodology

How This Model Works

From Journey to Numbers

Customer Journey → Inflection points define where loyalty is built or blocked.

Service Blueprint → Maps every planned interaction.

Service Moments → Specific actions with designed effort: preparation + execution + follow-through.

Capacity → Availability minus demand, adjusted for ramp and reactive load.

Key Assumptions

Target Availability ≠ 100%. Indirect and unplanned work consume ~35%.

Planning model, not precision forecast. The value is directional confidence.

Spreadsheet logic translated faithfully. Growth cohorts cascade demand. OB and CSM distinct. Hire ramp reduces contribution.
